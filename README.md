# PHP2Shell 리서치 리포트

PHP2Shell(CVE-2026-109618·CVE-2026-109619)의 발견 배경, AI의 역할, 공격·탈취 흐름, 영향 범위와 방어 방법을 설명하는 한국어 리포트입니다.

**조사 기준일: 2026년 10월 24일(KST).** PHP의 10월 23일 후속 설정 권고를 반영했으며, 공식 보안 권고와 발견팀·보안업체의 1차 자료 13개를 연결했습니다.

## 열어 보기

저장소를 내려받은 뒤 [php2shell-report.html](php2shell-report.html)을 브라우저에서 엽니다. 별도 설치나 빌드가 필요 없습니다.

- CSS·JavaScript·SVG를 HTML 한 파일에 포함
- 라이트모드 전용, 시스템 폰트 사용
- Google Fonts와 외부 폰트·CDN·분석 스크립트 호출 없음
- 모바일·데스크톱 반응형 화면과 인쇄/PDF 저장 지원

출처 링크를 열 때는 인터넷 연결이 필요합니다. 일부 상호작용은 JavaScript를 사용합니다.

## 주요 내용과 기능

- 페이지 상단 목차와 현재 읽는 섹션 표시
- 사건 요약과 발견·공개 연혁, 연구자와 AI의 역할
- 두 취약점의 원리와 메모리 상태 비교 도식
- 공격 경로별 단계 탐색과 데이터 탈취 흐름
- 영향 범위, 공격 시도와 침해 성공의 구분
- 패치 버전표와 브라우저 안에서 동작하는 버전 대조 도구
- 운영 대응 체크리스트, 설명·점검·설정·컨테이너 코드 탭과 복사
- 자주 생기는 오해와 원문 출처

버전 대조 도구는 입력 문자열과 리포트의 버전표만 비교하며 서버 스캔을 수행하지 않습니다. 코드 예시도 이 페이지에서 실행되지 않습니다. 보안 대응 시에는 최신 PHP·공급자 공지를 함께 확인하세요.
